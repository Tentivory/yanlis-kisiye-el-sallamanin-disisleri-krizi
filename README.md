# T.C. Yanlış Kişiye El Sallama Dışişleri Kriz Merkezi

> **UYARI:** Bu yazılım bir şaka değildir. Şaka gibi duruyorsa protokolü doğru okumamışsınızdır.

Sokakta, otobüste, market kuyruğunda veya zoom arka planında **yanlış insana el salladınız**. Karşı taraf size bakıyor. Siz hâlâ sallıyorsunuz. Tarih bu anı kaydetti. Devlet de kaydetsin diye buradayız.

## Ne yapar?

- Krizin diplomatik seviyesini ölçer (1 = "yanlış akraba", 10 = "BM Genel Kurulu önünde tanımadığın adama el")
- Resmî özür notu üretir
- Konsolosluk koruması talep eder (talep edilir, verilmez)
- Elinizi bir daha kaldırmamanız için bilimsel olmayan tavsiye verir

## Kurulum

```bash
python3 kriz.py
```

Bağımlılık yoktur. Utanç yeterlidir.

## Örnek çıktı

Program size sorar: kimi sandınız, kim çıktı, kaç saniye salladınız, gülümsediniz mi.
Sonra A4 formatında kriz tutanağı basar. Yazıcınız yoksa vicdanınıza basar.

## Yasal uyarı

Bu proje:
- Dışişleri Bakanlığı'nın resmi yazılımı **değildir**
- El sallamayı yasaklamaz, sadece belgeler
- Patates içermez (talep üzerine)
- ISO-9001 belgesizdir çünkü belgelendirme kurulu da yanlış kişiye el sallamıştır
